# AI Collaboration Contract

Keep changes scoped to the user's request. Inspect the current repository and relevant upstream documentation before editing. Do not treat a request for explanation or diagnosis as permission to change code.

Preserve the hardware configuration documented in `README.md`: the SHT40 uses 3V3, GND, GP0/SDA, and GP1/SCL. Do not claim on-device behavior passed from compilation alone. Hardware-dependent verification requires logs or observations from the physical Pico, either gathered directly when available or reported by the user.
